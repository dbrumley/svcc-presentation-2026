The patch is localized.

The fix sits right where it crashes — on the backtrace. If the copy would overflow, exit; the same exploit input hits the guard and the shell never pops.

The hard ones aren't — the real fix can live upstream, off the backtrace.

The fix isn't on the backtrace.

Backtrace at crash
#0 free(obj) crash · the AI patches here
#1 on_render(view)
#2 event_loop()
#3 main()
↳ but the real bug is somewhere else
The real fix — off this stack
double free — obj was already freed in on_close(), a different event
missing filter — the check belongs upstream in parse(), not at the use
Root cause

Localized fixes — right at the crash — are solved.

The cause is often somewhere the backtrace never points.

Today's models fall off the moment the fix leaves the stack — upstream, or in another event entirely.

But "is the fix at the root cause?" is measurable — so it's trainable.
